# Solana Wallet Dashboard

A lightweight dashboard for exploring Solana wallet balances and recent on-chain activity.

## Live Demo

https://0xhexor-ux.github.io/solana-wallet-dashboard-/

## Features

- View SOL wallet balance
- Explore recent on-chain transactions
- Search any Solana wallet address
- Simple, responsive interface
- Built with vanilla HTML, CSS and JavaScript
- Uses Solana JSON-RPC through a secure backend proxy

## Tech Stack

- HTML
- CSS
- JavaScript
- Solana JSON-RPC
- Cloudflare Workers
- GitHub Pages

## Why I Built This

I wanted to build something small but practical while learning more about Solana development and on-chain data.

This project is part of my journey from researching Web3 protocols to building hands-on applications.
